### Suite of minigames playable on APC Mini Mk2!

![An AKAI APC Mini Mk2](https://cdn.builder.io/api/v1/image/assets%2F47c5d023e7b3451a86ac03602c65dce8%2Ff559e063b06e4e198e850b1e9e932896)

## Available games
At this moment, the following games are available:
- Snake
- Tetris
- Stacker
- Space Invaders
- Whack-a-Mole

## How to play
1. Open a terminal.
2. Clone this repository and navigate to it.
3. Install the required dependencies:
    ```bash
    npm install
    ```
4. Run the app:
    ```bash
    npm start
    ```
5. Enter the name of the game you want to play.
6. **Have fun!**

> [!NOTE]
> This project has been developed and tested on a Linux Mint device.  
> I cannot guarantee that it will work for Windows, Mac and other
> Linux distributions at this moment.  
> If you experience errors on your platform, feel free to open an issue!
